# Persona Session Reports

Final round, build 5.8.0. Each persona followed the eight-step protocol in a real Chromium browser. The team's sign-in was placed in the browser before each session, as the ground rules require. No final assessment was submitted. The two state-changing actions (one activity resubmission, one instructor review) and the three launch journeys ran only on the re-seedable staging site. External services (payment gateways, AI, video) were stand-ins: the PayPal "approve" step returned straight to the LMS, so no session left the staging site.

**Offering types.** Staging has one offering type, so all groups ran on "AI Fluency for the Workplace" (the micro-credential). Group 2 treated it as the certification track. Group 3 used the instructor's Cohort, Assessments and Payment Settings screens as the enterprise manager's view.
